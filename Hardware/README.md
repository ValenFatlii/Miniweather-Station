# PCB Design

This folder contains the PCB design files for the ESP32-based Miniweather Station.

The custom PCB integrates:

- ESP32 controller
- Power management circuit
- I2C sensor interface
- SD card interface
- Power monitoring circuit


## PCB Design Files

| File | Description |
|---|---|
| Schematic | Electrical circuit design |
| PCB Layout | PCB routing and component placement |
| 3D View | PCB mechanical visualization |
| Gerber Files | Manufacturing files |


## Design Considerations

The PCB design focuses on:

- Stable power distribution
- Compact component arrangement
- Noise reduction through proper grounding
- Easy sensor and peripheral connection
