# <p align="center">1. Project Overview</p>

## Overview

The Miniweather Station is an IoT-based environmental monitoring system developed to measure and record multiple atmospheric parameters using an ESP32 microcontroller as the main processing unit.

This project aims to develop a low-cost, modular, and autonomous weather monitoring platform capable of collecting environmental data periodically, storing measurement results locally, and transmitting data through wireless communication for remote monitoring.

The system integrates several environmental sensors to measure air temperature, relative humidity, carbon dioxide concentration, atmospheric pressure, light intensity, wind direction, wind speed, rainfall, and additional environmental parameters. The collected data is processed by the ESP32 and stored in a local SD card while also being transmitted through MQTT communication when an internet connection is available.

---

# 1.1 Project Objectives

The main objectives of this project are:

- Design and develop a modular IoT-based weather station prototype.
- Integrate multiple environmental sensors into a single embedded monitoring system.
- Develop a reliable data acquisition system using ESP32.
- Implement local data logging using a microSD card for offline operation.
- Enable wireless data transmission using WiFi and MQTT protocol.
- Evaluate the performance and reliability of the developed weather station system.
- Develop a platform that can support long-term environmental monitoring applications.

# 1.3 System Concept

The weather station consists of four main layers:

## Sensor Layer

The sensor layer is responsible for collecting environmental information from the surrounding area. Multiple digital sensors are integrated using different communication interfaces such as I2C, SPI, and GPIO interrupt-based measurement.

## Processing Layer

The ESP32 microcontroller acts as the central processing unit. It performs:

- Sensor data acquisition
- Data processing and conversion
- Measurement interval control
- Data formatting
- System management

## Communication Layer

The system uses wireless communication to transfer measurement data.

Main communication features:

- WiFi connectivity
- MQTT-based data transmission
- Remote monitoring capability

## Storage Layer

To ensure data availability during network interruptions, the system implements local data storage using a microSD card.

The system follows an offline-first approach:

1. Sensor data is collected.
2. Data is processed by ESP32.
3. Measurement results are stored locally.
4. Data is transmitted when network connectivity is available.
