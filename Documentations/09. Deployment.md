# Deployment

## Overview

The Miniweather Station was deployed as an outdoor environmental monitoring prototype at the rooftop of the Department of Nuclear Engineering and Engineering Physics (DTNTF), Universitas Gadjah Mada.

The deployment stage aims to evaluate the performance of the developed weather station under real environmental conditions while ensuring reliable operation of the sensing system, power supply, data storage, and wireless communication.

The deployed system integrates:

- Environmental sensors
- ESP32-based control system
- Solar-powered energy system
- Local data storage
- MQTT-based wireless communication
- Hyperbase monitoring platform

The current deployment is part of an ongoing field evaluation process to observe system stability and measurement performance during continuous operation.

# Enclosure Design

## Material Selection

The weather station enclosure is fabricated using PETG material due to its:

- Better outdoor durability compared with PLA
- Higher temperature resistance
- Improved mechanical strength
- Suitability for 3D printing fabrication

# Sensor Placement

Proper sensor placement is required to ensure representative environmental measurements.

The sensor assembly consists of:

- Solar radiation shield
- Light sensor dome
- Wind direction sensor
- Wind speed sensor
- Rainfall sensor

---

# Solar Radiation Shield

The SCD40 and BMP280 sensors are installed inside a solar radiation shield.

The radiation shield functions to:

- Reduce direct solar heating
- Improve temperature and humidity measurement accuracy
- Protect sensors from rain exposure
- Maintain airflow around the sensors

![Radiation Shield](../images/radiation_shield.jpg)

*Figure 6. Solar radiation shield containing SCD40 and BMP280 sensors.*

# Light Sensor Placement

The BH1750 light intensity sensor is installed inside a dome structure located at the uppermost part of the sensor assembly.

The placement is intended to:

- Maximize exposure to ambient light
- Reduce shading effects
- Improve light intensity measurement reliability

![Light Sensor Dome](../images/light_sensor_dome.jpg)

# Wind Sensor Orientation

The wind vane is calibrated and aligned toward geographic north during installation.

This alignment ensures:

- 0° corresponds to north direction
- Consistent wind direction measurement
- Reduced directional measurement error

The wind direction calibration follows the AS5600 reference calibration procedure.

---

# Solar Panel Orientation

The solar panel is oriented toward the south during deployment.

The orientation is selected to optimize solar energy harvesting according to the installation location.

The solar panel provides energy input for:

# Installation Procedure

The deployment procedure consists of the following steps:

1. Prepare the rooftop installation location.
2. Install the mounting structure.
3. Install the battery enclosure.
4. Install the solar panel.
5. Install the control enclosure.
6. Install the sensor assembly.
7. Install the solar radiation shield.
8. Align the wind vane toward north.
9. Connect the power system.
10. Verify ESP32 operation.
11. Verify sensor readings.
12. Verify SD card data logging.
13. Verify MQTT communication.
14. Confirm data visualization on Hyperbase.
