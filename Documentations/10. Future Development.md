# 10 Future Development

This roadmap lists proposed improvements outside the 10 November 2026 production baseline. Each item requires an implementation version and its own acceptance evidence.

## Production OTA

The WiFi/RSSI GitHub OTA test is a separate experiment. Integrating OTA into the full station requires application/partition-size assessment, authenticated HTTPS and firmware integrity/authenticity checks, boot validation/rollback behavior, controlled failure/retry handling, and tests for interaction with sampling, SD, and modem recovery.

Do not treat the existing `OTA-Test/manifest.json` or test releases as production weather-station firmware. Their endpoints are left unchanged by this documentation synchronization.

## Configuration provisioning

Design persistence/provisioning for two WiFi profiles and service parameters, for example with NVS. The test sketch's `SET_WIFI` commands are not currently implemented in the production sketch.

## Communication confirmation and security

Enable and maintain server certificate validation for WSS. Add application/database acknowledgements if supported, and validate timestamp mapping and `message_id` deduplication so broker ACKs are not mistaken for storage receipts.

## Hardware and power

Reconcile the as-built PCB, BOM supplier codes, PDF layers, manufacturing files, and harness records. Measure modem startup/transmission transients, converter temperatures, load-path coverage, controller cutoff behavior, and battery runtime under recorded conditions.

Low-power scheduling and state-of-charge estimation require validated measurement methods and must preserve the acquisition requirements.

## Storage and measurement quality

Evaluate safe journal compaction/log rotation, fuller field diagnostics, power-loss recovery, sensor validity/coverage metadata, and the effects of sampling delays. Extend calibration and field tests across the required operating range and environmental exposure.

Image and diagram revision is a separate owner-led task; this update intentionally preserves the existing graphics and image references.
