# Calibration and Testing

## Overview

The Miniweather Station undergoes calibration and functional testing to evaluate measurement accuracy, system reliability, and operational performance.

The validation process consists of:

1. Sensor calibration and validation
2. Hardware functional testing
3. Communication testing
4. Data logging verification
5. Outdoor deployment evaluation

Sensor validation is performed by comparing the developed weather station measurements with reference instruments and commercial measurement devices.

# Sensor Calibration and Validation

## Calibration Approach

Each sensor is evaluated by comparing the Miniweather Station output with a reference measurement device.

The evaluation uses statistical performance indicators:

| Metric | Purpose |
|-|-|
| R² | Correlation between developed sensor and reference |
| MAPE | Average percentage measurement error |
| RMSE | Root mean square error |
| MAE | Average absolute error |

The calibration process aims to improve measurement reliability and quantify the accuracy of the developed system.

# Wind Direction Calibration

## AS5600 Wind Direction Sensor

The AS5600 is used as a digital wind vane angle sensor.

## Calibration Method

The wind direction reference point is determined by aligning the sensor orientation with geographic north.

Calibration procedure:

1. Determine mechanical zero position.
2. Align wind vane direction with north.
3. Compare angular output with magnetic compass.
4. Apply correction offset if required.

# Communication Testing

The communication system is tested to verify data transmission reliability.

Testing includes:

- WiFi connection
- MQTT connection
- Hyperbase data reception


The communication test verifies:

1. ESP32 successfully connects to network.
2. MQTT connection is established.
3. Measurement data is transmitted.
4. Data appears correctly on Hyperbase dashboard.
